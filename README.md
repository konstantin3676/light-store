## Итоговый проект по дисциплине "Веб-разработка"

### Описание

Магазин лампочек.

### Запуск dev сервера

`docker compose up -d --build`

Сервис продуктов доступен на http://localhost:8001/api/docs, сервис заказов - http://localhost:8002/api/docs, API Gateway - http://localhost:8000/api/docs, фронтенд - http://localhost:5173, админка - http://localhost:5173/admin
